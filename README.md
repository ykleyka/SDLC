# Проект «Идеальный день»

**Автор:** Валентин Чалей<br> 
**Дисциплина:** Жизненный цикл разработки программного обеспечения

## Описание

Приложение «Идеальный день» разработано на языке C# с использованием Windows Forms. Программа позволяет указать время сна, работы и подъёма, автоматически рассчитать время отдыха, оценить баланс дня и предложить альтернативное расписание.
