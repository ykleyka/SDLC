# EvenUp — учёт совместных расходов

**Автор:** Чалей В. В., гр. 450504<br>
**Дисциплина:** Жизненный цикл разработки программного обеспечения

## О проекте

EvenUp — веб-приложение, в котором друзья объединяются в группы (поездка, съёмная квартира, вечеринка), записывают общие траты и сразу видят, кто кому сколько должен. Приложение считает балансы участников и предлагает минимальный список переводов, после которого все долги закрыты. В группу можно добавить человека без аккаунта, а потом он сможет «забрать» свою историю, зарегистрировавшись.

**Стек:** C#, .NET 10, ASP.NET Core Blazor Web App (Interactive Server), EF Core + SQLite, ASP.NET Core Identity.
