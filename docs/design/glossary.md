# Глоссарий EvenUp

Краткие термины предметной области для ЛР №5. Полные определения и технические сокращения находятся в [SRS, раздел 1.3](srs.md#13-definitions-acronyms-and-abbreviations).

| Термин | Определение |
|---|---|
| Группа | Пространство, в котором участники ведут общие расходы. |
| Участник | Человек, чьи расходы и доли учитываются в группе; может быть зарегистрированным или виртуальным. |
| Виртуальный участник | Участник, добавленный по имени без аккаунта. |
| Трата | Расход группы с плательщиком и участниками, между которыми распределяется сумма. |
| Доля | Часть траты, отнесённая на одного участника. |
| Баланс | Разница между оплаченными суммами и долями участника. Положительный баланс означает, что участнику должны. |
| Погашение | Запись о переводе между участниками в счёт долга. |
| Регулярная трата | Шаблон ежемесячного расхода, из которого система создаёт обычные траты. |
| Приглашение | Ссылка, по которой пользователь может вступить в группу. |
